## Notes

- The photographer names above are best-effort from Commons metadata. **Verify each on Commons after downloading** — Commons can move files, change attribution, or revise licences. If an image was renamed or removed, replace it and update this file.
- The CC BY-SA licence requires attribution alongside the image. In Phase 4 the in-app sources expander will display this attribution; until then this file is the canonical record.
- The Kumari is not depicted in any image. (BRIEF §3.5, CLAUDE §3.10.)
- Any image where the original copyright is unclear is removed; "fair use" doesn't apply in a distributed app.
